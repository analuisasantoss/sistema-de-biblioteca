# Sistema de Gerenciamento de Biblioteca
## Descrição
Esse projeto é um sistema de gerenciamento de livros desenvolvido em Python.
O sistema ajuda a cadastrar, listar, buscar, emprestar e devolver livros, além de organizar os livros por título, autor ou ano de publicação. Os dados são armazenados no arquivo `livros.csv`, possibilitando que sejam recuperados quando o programa for iniciado novamente.

## Funcionalidades

* Cadastrar livros
* Listar livros
* Buscar por título ou autor
* Registrar empréstimos
* Registrar devoluções
* Ordenar por título, autor ou ano
* Salvar e carregar os dados dos livros

## Tecnologias utilizadas

* Python
* Git e GitHub
* Arquivo CSV (`livros.csv`)
O projeto utiliza apenas a biblioteca padrão do Python, sem dependências externas.

## Exemplo de uso
Ao iniciar o programa, será apresentado o seguinte menu:
SISTEMA DA BIBLIOTECA
1 - Cadastrar livros
2 - Registrar empréstimo
3 - Registrar devolução
4 - Listar livros
5 - Buscar livro
6 - Ordenar livros
7 - Sair
O usuário deve escolher uma das opções para realizar a operação desejada..
